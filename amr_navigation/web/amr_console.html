      Collision avoidance while you drive

      The watch angle is the width of the wedge, either side of the direction of travel, that is checked for obstacles. If lidar data stops arriving, driving forward and backward is blocked.

      Guard while navigating

      This watches the robot's real movement from odometry, so it also covers goals sent from other tools.

      Obstacle margins in Nav2

      Keep-away sets the inflation radius. Larger values make paths stay further from walls. The lowest value is just above your 0.13 m robot radius. Clearing costmaps removes obstacles left behind by moved objects.

      Nav2 speed limits

      Sets the DWB controller's max_vel_x / max_speed_xy and max_vel_theta on the controller_server. Your velocity smoother caps at 0.30 m/s and 1.5 rad/s, so the sliders stop there. Changes last until Nav2 restarts; edit nav2_params.yaml to keep them.

      Connect to the robot

      On the laptop, install and start rosbridge, then press Connect above.

      sudo apt install ros-humble-rosbridge-suite ros2 launch rosbridge_server rosbridge_websocket_launch.xml

      Data arriving from the robot

        If a topic exists but stays silent here, check its QoS with ros2 topic info -v. Best-effort sensor topics need a matching rosbridge version.
